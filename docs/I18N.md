# Languages (i18n)

The product UI is **English**. All UI text lives in one place so a
regional language can be added without touching components:

- File: `web/src/i18n.js` — `messages.en` holds every translated
  string under keys like `console.saveRate`.
- Components render text with `t("console.saveRate")`.
- The sidebar language selector lists every language present in
  `messages` automatically; the choice is stored per device
  (`ss_lang` in localStorage).

## Adding a language (e.g. Hindi)

1. In `web/src/i18n.js`, add a block next to `en`:

   ```js
   hi: {
     "common.received": "प्राप्त",
     // ...same keys as en, translated
   },
   ```

2. Add its label in `availableLangs` (`hi: "हिन्दी"` is already
   mapped).
3. Done — "हिन्दी" appears in the sidebar selector. Any key not yet
   translated falls back to English, so a language can be added
   gradually.

## Rule for new UI text

New screens/sections must add their strings to `messages.en` and use
`t()` — never hardcode a second language into a component. Older
screens still have hardcoded English strings; they migrate to keys
as they are touched.
